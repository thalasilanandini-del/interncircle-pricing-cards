# Responsive SaaS Pricing Cards

A modern and responsive SaaS pricing card component developed as part of my InternCircle Web Development Internship.

## About the Project

This project demonstrates a responsive pricing section with multiple subscription plans. Users can switch between monthly and yearly billing, and the displayed prices update dynamically using JavaScript.

## Features

- Responsive SaaS pricing cards
- Monthly and yearly billing toggle
- Dynamic price updates
- Popular plan badge
- Best Value badge
- CSS hover effects
- CSS transitions and transforms
- Responsive layout for desktop, tablet and mobile
- Interactive pricing buttons
- Clean and modern user interface
